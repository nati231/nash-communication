# Nash

Nash is a real-time communication and collaboration platform designed for online meetings, communication, and teamwork.

## Vision

Nash will provide users with a single platform for:

- Multi-user video calling
- Audio communication
- Screen sharing
- Real-time meeting chat
- File sharing
- Collaborative whiteboard
- Secure user authentication

## Core Technologies

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React

### Backend
- Node.js
- Express
- TypeScript
- Socket.IO

### Data
- PostgreSQL
- Prisma

### Real-Time Communication
- WebRTC
- Socket.IO

### Collaboration
- HTML Canvas
- Socket.IO

## Project Goals

This project is being built to gain practical experience with:

- Modern frontend development
- Backend development
- REST APIs
- WebSockets
- WebRTC
- Real-time communication
- Authentication
- Database design
- File handling
- Collaborative applications
